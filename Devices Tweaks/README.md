# Devices Tweaks
Anomaly detector and geiger counter will play their sounds just by being in the inventory (or only when equipped if enabled), the geiger counter keybind will only work if equipped and the anomaly detector will drain power when detecting anomalies.
Built-in compatibility for Beef's NVGs (with a small issue), GeigerHush and DAR/Arrival.
If using Beef's NVGs, the blank space in the on_key_release function will need to be manually deleted.
