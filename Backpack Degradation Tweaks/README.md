# Backpack Degradation Tweaks
Fixes a crash with backpack degradation enabled and now reduces carryweight based on condition.
By default backpack can only lose up to half its carryweight, change bkpk_weight_reduction_mul if a different multiplier is desired.
Requires Tosox's Re-enable Backpack Degradation: https://github.com/Tosox/Tosox-Mini-Mods-Repo
